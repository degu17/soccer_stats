# この数字、だれ？ — スタッツ探偵

選手の名前を伏せたまま、**スタッツ（成績の数字）だけ**で正体に迫る、スマホ向けのサッカー推理パズル。

名前も顔も知らない6人の容疑者。買える手がかりは6ポイント分。最後に2枚の証拠を重ねて、1人だけを告発する。サッカーの知識がなくても、容疑者カードの数字を比べれば解けるように作っています。

**▶ 遊ぶ:** https://degu17.github.io/soccer_stats/

（`main` に push すると GitHub Actions が `dist/` を GitHub Pages へデプロイします）

## この垂直スライスの内容

- **TUTORIAL「はじめての事件」** — 4人・4手がかり・約3分。ゲーム側が最初の手がかりを選び、交点の作り方を教えます。
- **FILE 001「途切れない線」** — 6人・8手がかり・約6分。遠藤保仁の26シーズンを、通算記録から読み解く。
- **FILE 002「左足の魔法」** — 6人・8手がかり・約7分。中村俊輔の二度のMVPと、13年離れた山を追う。
- 捜査メモ、誤告発、途中セーブ、自己ベスト、実績、用語ノート、正体コレクション、PWA（オフライン起動・ホーム画面追加）まで実装済み。
- 6人全員の写真とクレジットを収録済み。写真がない場合のシルエット表示もフォールバックとして残しています。

## 遊び方

1. **事件カード** — 無料の手がかりと、名前を伏せた「謎の選手X」を確認。
2. **容疑者を消す** — 6ポイントの予算で手がかりを買う。条件に合わない容疑者は×。手がかりは1〜3pt。
3. **2枚の証拠で告発** — 購入済みの手がかりから2枚を選び、容疑者1人を告発。
4. **正体判明 → 捜査報告書** — 写真・キャリアの物語・数字の読み方を確認。自己ベストを更新。

### 得点

| 項目 | 点 |
| --- | ---: |
| 正解 | +50 |
| 証拠（2枚がっちり／決定的＋補強／弱い） | +30 / +20 / +10 |
| 効率（残したポイント） | 最大 +20 |
| 誤告発 | −10（1回ごと） |

S ≥ 90 / A ≥ 75 / B ≥ 60 / C < 60。証拠を2枚買う必要があるため、事件ごとの実質満点は「最安のタイト証拠ペア」のコストで決まります（FILE 001は93点、FILE 002は90点）。

## ローカルで動かす

```bash
npm install
npm run dev
```

表示された URL を開いてください。スマホ実機で試すときは `npm run dev -- --host` を使い、同じ Wi-Fi からアクセスします。

ゲーム本体（HTML/CSS/JS）は **単一 HTML** にインライン化されます。PWA 用の manifest・Service Worker・写真・アイコンは `dist/` 内の別ファイルです。

```bash
npm run build
npm run preview
```

PWA のインストールとオフライン動作は、`localhost` か HTTPS で配信したときだけ有効です。`dist/index.html` を直接ダブルクリックすると、ゲーム本体は動きますが Service Worker は登録されません。

## テスト

```bash
npm run test:cases   # 3事件の候補者・手がかり・タイトな証拠ペア・得点経路を検証
npm test             # 型チェック + ビルド + チュートリアル→FILE 001→FILE 002 の通しプレイ
npm run test:all     # 上記すべて
```

`npm test` はインストール済みの Google Chrome を Playwright で操作し、390×844 と 375×667 でのはみ出し、コンソールエラー、誤告発からの復帰、リロード後の再開、v1→v2 のセーブ移行、GitHub Pages 風の `/soccer_stats/` サブパスでの PWA manifest・Service Worker・オフライン再読み込みまで確認します。スクリーンショットは `tests/shots/` に保存されます（Git 管理外）。

Lighthouse 12 をローカル本番ビルド（`/soccer_stats/`）に対して実行し、Accessibility / Best Practices / SEO は各100、Performance も参考値で100（モバイル、LCP 1.3s / TBT 0ms / CLS 0）を確認済みです。

## データと写真

- 選手データは英語版 Wikipedia のキャリア成績表と J.League Data Site を基準に、**リーグ戦のみ**へ揃えています。カップ戦・代表戦は通算に含めていません。
- 年齢は各シーズン開始時点の満年齢。MVP の受賞年齢は、容疑者カードで手がかりとして使えるように表示しています。
- 写真は Wikimedia Commons の自由ライセンス作品（CC BY / CC BY-SA）を、網点加工・トリミングして使用しています。作者・ライセンス・出典はゲーム内のクレジット画面に表示します。
- 遠藤保仁・中村俊輔・中田英寿に加え、小野伸二・稲本潤一・中村憲剛の写真も収録済みです。作者・ライセンス・原画ページは全員分をクレジット画面に掲載しています。
- 未確認の事実がある選手は、公開前に出典を確定してください。特に小野・稲本・憲剛の所属クラブ数・海外国数・最終季は暫定値です。
- 本作は非公式のファンメイド作品です。各クラブ・リーグ・選手・団体とは関係ありません。一般公開する場合は、肖像・パブリシティの扱いを専門家に確認してください。
