# この数字、だれ？ — スタッツ探偵

選手の名前を伏せたまま、**スタッツ（成績の数字）だけで正体に迫る**サッカー推理クイズ。
スタッツを知らない人でも、推理しながら「数字の読み方」が身につくように作っています。

## 遊び方（ローカル）

- **いちばん簡単**: `dist/index.html` をブラウザで開く（ダブルクリックでOK）。
  - `dist/players/` の写真と同じフォルダ構成のまま開いてください。
  - フォントは Google Fonts から読み込みます（オフライン時は端末のフォントで表示）。
- **開発サーバー**: `npm install` → `npm run dev` → 表示された URL を開く。
- スマホで試す: `npm run dev -- --host` で同じ Wi-Fi の端末から開けます。

## デザイン

探偵の捜査ファイル × 古いサッカー年鑑。新聞紙の上に黒と朱色の2色インクで刷ったような紙面で、プレイヤーの推理はすべて**青鉛筆**、事実は**朱色の印刷**で描き分けています。事件簿は台帳、手がかりはスカウティング・レポート、正体はクリップ留めの網点写真、評価はかすれたゴム印。効果音もタイプライターのキーとベル、判子の音で揃えています（すべて WebAudio で生成）。

## ゲームの流れ（1人＝1事件、約3分）

1. **数字の目利き** — 物差しで「最多得点」や「通算出場」を予想。近さで採点し、ほかの9人と並べた物差しで相場を体感。
2. **プロファイリング** — スカウティング・レポートの6項目から FW / MF / DF / GK を見抜く。決め手は「1試合あたり得点」。
3. **キャリア・ドロー** — 移籍・ケガ・2部などのイベントとリーグ帯をヒントに、毎シーズンの数字を指でなぞって描く。本物の線と重ねて一致度を採点。
4. **容疑者の特定** — 4択で正体当て（わからなければスキップ、減点なし）。
5. **正体判明 → 数字の物語** — 顔写真と、グラフの山や谷に隠れたエピソード。

ランク（S/A/B/C）・自己ベスト・用語ノート（11語）・全10事件クリアの総合結果があります。進行状況はブラウザ（localStorage）に保存されます。

## データと写真

- 成績: 英語版 Wikipedia の「Career statistics」表から**リーグ戦のみ**を抽出（カップ戦・代表戦は含まない）。シーズン途中の移籍は同じシーズンに合算。全員、表の通算値と一致することを確認済み（中村俊輔は表の通算行に誤りがあるため、クラブ別小計の合計を採用）。
- 年齢: 各シーズン開始時（7月1日時点）の満年齢。
- 解説文の事実: 日本語版 Wikipedia の本文で確認したものだけを使用。
- 写真: Wikimedia Commons の自由ライセンス作品（CC BY / CC BY-SA）を顔中心にトリミング。作者・ライセンス・出典はゲーム内の「数字の物語」画面とクレジット画面に表示。
- 非公式のファンメイド作品で、各クラブ・リーグ・選手とは関係ありません。一般公開する場合は、肖像・パブリシティの扱いを専門家に確認してください。

## 開発

```
npm run build              # 型チェック + dist/index.html（単一ファイル）を生成
node tests/playtest.mjs    # 6種類の画面サイズで1事件を通しプレイし、はみ出し・エラーを検査
node tests/fullrun.mjs     # タッチ操作で10事件を連続クリアして結果画面まで確認
```

テストはインストール済みの Google Chrome を使います（スクリーンショットは `tests/shots/`）。

- `src/data/` 選手データ（`seasons.json` は抽出済みの成績、`players.ts` に紹介文・イベント・物語）
- `src/lib/` 採点・統計・効果音（WebAudio で生成）・保存
- `src/components/CareerChart.tsx` 描画と答え合わせのグラフ
- `src/screens/` 各画面
