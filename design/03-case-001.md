## 4. 推理の構造

### 4.1 2×2の論理グリッド

無料の手がかり適用後の5人を、2つの属性で分ける。

```
                  通算100得点以上
                     ○        ×
海外経験なし  ○   遠藤      憲剛
              ×   俊輔      小野・稲本
```

- 海外経験なし → {遠藤, 憲剛}
- 通算100得点以上 → {遠藤, 俊輔}
- 両方の交点 → **遠藤のみ**
- 俊輔は「得点は高いが海外経験あり」
- 憲剛は「海外未経験だが得点は83」
- 小野・稲本はどちらも外れる

**この事件の芯:** 遠藤と憲剛のペア、遠藤と俊輔のペアを、それぞれ別の手がかりで切る。片方だけでは2人残る。**2枚の手がかりの交点が1人になる**のが、この事件の気持ちよさ。

### 4.2 手がかりの残存集合

| 手がかり | 残る容疑者 | 単独で1人？ |
|---|---|---|
| C1 海外なし | 遠藤、憲剛 | いいえ |
| C2 クラブ4以下 | 遠藤、憲剛 | いいえ |
| C3 通算100点 | 遠藤、俊輔 | いいえ |
| C4 代表100+ | 遠藤 | **はい（決定的）** |
| C5 J1優勝2+ | 遠藤、憲剛 | いいえ |
| C6 30代MVP | 遠藤、俊輔、憲剛 | いいえ |
| C7 最終季J2 | 遠藤、俊輔 | いいえ |

### 4.3 タイトな証拠ペア（2枚とも必要）

A群（遠藤・憲剛）とB群（遠藤・俊輔）のクロス。

| A群の手がかり | B群の手がかり | コスト | 証拠 |
|---|---|---:|---|
| C1 海外なし（1） | C7 最終季J2（1） | **2pt** | タイト |
| C1 海外なし（1） | C8 身長178（1） | **2pt** | タイト |
| C2 クラブ4以下（1） | C7 最終季J2（1） | **2pt** | タイト |
| C2 クラブ4以下（1） | C8 身長178（1） | **2pt** | タイト |
| C1（1） | C3 通算100点（2） | 3pt | タイト |
| C2（1） | C3（2） | 3pt | タイト |
| C5 J1優勝2+（2） | C7（1） | 3pt | タイト |
| C5（2） | C8（1） | 3pt | タイト |
| C5（2） | C3（2） | 4pt | タイト |

**最安のSルート:** C1（またはC2）＋C7（またはC8）＝**2pt**。  
**安全だが高いルート:** C4（3pt）＋任意の関連手がかり（1pt）＝4pt。証拠は「決定的＋補強」で20点。Sは難しい。

### 4.4 相性の悪い組み合わせ（学びのポイント）

| 組み合わせ | 残る容疑者 | 何が起きる？ |
|---|---|---|
| C1 海外なし ＋ C5 J1優勝2+ | 遠藤、憲剛 | 同じA群。2人残る |
| C3 通算100点 ＋ C7 最終季J2 | 遠藤、俊輔 | 同じB群。2人残る |
| C6 30代MVP ＋ C1 海外なし | 遠藤、憲剛 | C6が弱く、C1と同じA群に寄る |
| C6 30代MVP ＋ C3 通算100点 | 遠藤、俊輔 | C6が弱く、C3と同じB群に寄る |
| C4 代表100+ ＋ C1 海外なし | 遠藤 | 有効だが「1枚で決まる」ので証拠20点 |

**C6は「買うと損をする」わけではないが、証拠ペアとしては弱い。** 3枚買ってC1＋C3のペアを選べばタイトな証拠になるが、C6の2ptは効率点を削る。ファンには「30代MVP」という物語が刺さるが、Sを狙うなら買わない。この「情報として面白いが、効率は悪い」手がかりが、リプレイの判断を生む。

## 5. 想定ルートとスコア

### ルートA: 最安S（推奨）

1. 無料の手がかりで中田英寿が消える（残り5人）。
2. C1「海外なし」を買う（1pt）→ 遠藤、憲剛（2人）。
3. C7「最終季J2」を買う（1pt）→ 遠藤、俊輔（2人）。
4. 交点は遠藤のみ。C1＋C7を証拠に告発。
5. 結果: 正解50＋タイト30＋効率13＝**93点 / S**。

**プレイヤーの思考:**  
「海外なしで遠藤と憲剛。最終季J2で遠藤と俊輔。両方にいるのは遠藤だけ。憲剛はJ1で終わっているし、俊輔は海外に行っている。だから遠藤だ。」

### ルートB: 別の最安S

1. C2「クラブ4以下」（1pt）→ 遠藤、憲剛。
2. C8「身長178」（1pt）→ 遠藤、俊輔。
3. 交点は遠藤。C2＋C8で**93点 / S**。

### ルートC: 安全なA

1. C4「代表100+」（3pt）→ 遠藤のみ。
2. C1「海外なし」（1pt）→ 遠藤、憲剛。
3. 証拠はC4＋C1。C4だけで決まるため「決定的＋補強」の20点。
4. 正解50＋証拠20＋効率7＝**77点 / A**。

**学び:** 強い手がかりは安全だが、Sにはならない。安い手がかりを2枚組み合わせる方が、証拠として美しい。

### ルートD: 3枚買ってしまう

1. C1「海外なし」（1pt）→ 遠藤、憲剛。
2. C3「通算100点」（2pt）→ 遠藤、俊輔。
3. C5「J1優勝2+」（2pt）→ 遠藤、憲剛。
4. 3枚で5pt。残りは遠藤のみ。
5. 証拠にC1＋C5を選ぶと、2人残るのでペア無効。証拠10点。
6. 正解50＋証拠10＋効率3＝**63点 / B**。

**学び:** 「3枚買えば安心」ではない。証拠は2枚。**どの2枚で1人に絞れるか**を考えるのが大事。C1＋C3、またはC3＋C5を選べばタイト30点で83点 / A。C6を追加すると予算オーバーになる。

### ルートE: 誤告発

1. C1＋C7で遠藤に絞る。
2. 間違えて憲剛を告発 → -10、憲剛が消える。
3. 遠藤を告発し直す。証拠はC1＋C7のまま。
4. 正解50＋タイト30＋効率13－10＝**83点 / A**。

**学び:** 間違えても事件は続く。ただしSは逃げる。誤告発を減らすことが、Sへの近道。

### スコア分布の目標

| ランク | 目標割合 | 想定 |
|---|---:|---|
| S | 35〜45% | C1/C2＋C7/C8の2ptルートを見つけた |
| A | 35〜40% | 4pt前後、または誤告発1回 |
| B | 15〜20% | 5pt以上、または証拠ペアを間違えた |
| C | 5%以下 | 証拠なし、誤告発2回以上 |

最初の通常事件なので、Sはやや多め（40%前後）を狙う。Vol.1後半の事件ではS 20〜25%まで下げる。

## 6. 告発と証拠の具体例

### 6.1 正解の告発

```
告発する容疑者: 遠藤保仁
証拠1: C1 海外キャリア → 「ない」
証拠2: C7 最終シーズン → 「2部」

判定:
  無料の手がかり適用後: 5人
  C1の残存: 遠藤、憲剛（2人）
  C7の残存: 遠藤、俊輔（2人）
  積集合: 遠藤（1人）
  → ペア有効、両方必要 = タイト
  → 証拠30点
```

### 6.2 有効だがタイトでない告発

```
告発する容疑者: 遠藤保仁
証拠1: C4 日本代表 → 「100試合以上」
証拠2: C1 海外キャリア → 「ない」

判定:
  C4の残存: 遠藤（1人）
  C1の残存: 遠藤、憲剛（2人）
  積集合: 遠藤（1人）
  → ペア有効だが、C4だけで決まる
  → 証拠20点
```

### 6.3 弱い告発

```
告発する容疑者: 遠藤保仁
証拠1: C1 海外キャリア → 「ない」
証拠2: C5 J1優勝 → 「2回以上」

判定:
  C1の残存: 遠藤、憲剛
  C5の残存: 遠藤、憲剛
  積集合: 遠藤、憲剛（2人）
  → ペア無効。関連する手がかりは2枚ある
  → 証拠10点
```

この場合、正解でも「まだ憲剛が残っている」ため、証拠としては弱い。告発前のプレビューで「あと1人残ります」と表示し、別の組を促す。

### 6.4 誤告発

```
告発する容疑者: 中村憲剛
証拠: C1＋C7

判定:
  憲剛はC1に該当するが、C7（最終季J2）に該当しない。
  → 不正解。-10点。憲剛を×にして捜査へ戻る。
  → ヒント: 「C7は、憲剛さんと矛盾します。憲剛さんの最終季はJ1です。」
```

## 7. 開示（リビール）

### 7.1 正体

**遠藤保仁**  
MF / 日本 / 1980年1月28日 / 178cm / 右足  
1998–2023 / 26シーズン / リーグ通算775試合・113得点 / 日本代表152試合

**キャッチコピー:**  
「18歳でデビュー、43歳で引退。線は、静かに長く続いた。」

### 7.2 物語（3ビート）

1. **1998年、18歳でプロへ**  
   横浜フリューゲルスでデビュー。翌年は京都パープルサンガへ。2001年、ガンバ大阪に移る。ここから20年、ガンバの中心になる。

2. **2013年、J2でも33試合**  
   ガンバがJ2に降格。33歳の遠藤は残留し、33試合に出場。翌2014年、J1に戻ったチームを優勝に導き、J1 MVPに。年齢は34歳だった。

3. **2023年、43歳で引退**  
   40歳を過ぎてもジュビロ磐田で35試合に出場。日本代表152試合は歴代最多。43歳でスパイクを脱いだ。

### 7.3 数字の読み方（この事件の学び）

**テーマ: 通算記録は「長く続けた人」の記録。**

- 775試合は、26シーズンで割ると約29.8試合/年。**ほぼ毎年、リーグ戦の大半に出ていた**ということ。
- 113得点はMFとしては多い。でも1試合あたりに直すと **0.15点**。点取り屋ではなく、試合を組み立てる選手だった。
- 152キャップは、**選ばれ続けた**記録。1回の大会だけでなく、20年間、代表に必要とされた。
- 「通算」は「すごいプレーを1回した」ではなく、「同じレベルを長く続けた」証明。でも、**1試合あたりに直すと役割が見える**。

**用語ノートに追加:**

- 通算記録
- 1試合あたり得点
- キャップ数
- J1 / J2

### 7.4 他の容疑者はなぜ違うか（開示後に表示）

| 容疑者 | 決め手 |
|---|---|
| 中村俊輔 | 左足。海外（イタリア・スコットランド・スペイン）でプレー。所属6クラブ。J1優勝0回。 |
| 中田英寿 | 2006年に29歳で引退。2010年代の現役ではない。通算288試合。 |

**「最も近い容疑者」を明示する。** これが「似た6人」の設計の証拠。憲剛は「海外未経験」「クラブ1つ」「J1優勝3回」「30代MVP」と、遠藤と多くの共通点を持つ。だからこそ、B群の手がかり（得点・最終季・身長）が必要になる。

## 8. 制作メモ

### 8.1 データソース

- 遠藤保仁、中村俊輔、中田英寿: `src/data/seasons.json`（英語版WikipediaのCareer statisticsから抽出済み）。通算試合・得点は全リーグ合計。
- 小野伸二、稲本潤一、中村憲剛: 英語版WikipediaのCareer statistics（2026年10月時点）。リーグ戦のみ。
- 代表キャップ: 英語版WikipediaのInternational statistics。
- タイトル: 英語版WikipediaのHonours、Jリーグ公式。
- 身長・生年: 英語版WikipediaのInfobox。
- 写真: 既存3人（遠藤・俊輔・中田）は `public/players/` にあり。小野・稲本・憲剛は **未取得**。`photoStatus: "pending"`。

### 8.2 写真の扱い

- 著作権クリアを条件に、Wikimedia Commons等の自由ライセンス写真を使用。
- 顔中心にトリミングし、網点処理。クレジットと出典を `credits.json` に保持。
- 未取得の3人は、リリース前に必ず用意する。仮画像のまま出さない。
- 商用化時には肖像・パブリシティを再確認する（今回は保留）。

### 8.3 数字の確定ルール

- 通算試合・得点は**リーグ戦のみ**。カップ戦・代表戦・親善試合は含めない。
- シーズン途中の移籍は、同じシーズンに合算する（既存データと同じ）。
- 所属クラブ数は、シニアのクラブのみ。同じクラブへの復帰は1つ。レンタル先は別クラブ。
- 海外経験は、レンタルを含む。日本国内のみなら「×」。
- 最終季の階層は、引退シーズンのリーグ。海外は「海外」、5部以下は「下部」。
- J1優勝は、在籍クラブがJ1で優勝したシーズン。出場試合数は問わない（メンバーとして在籍）。
- J1 MVPは、Jリーグ年間MVP。受賞時の年齢は、シーズン開始時（7月1日）の満年齢。

### 8.4 この事件の調整ポイント

- **C1とC2は同じA群に絞る。** どちらも1pt。プレイヤーが「海外」に気づくか「クラブ数」に気づくかの2通りを用意する。
- **C3、C7、C8は同じB群に絞る。** C3だけ2pt、C7/C8は1pt。ファンは得点、非ファンは最終季や身長で解ける。
- **C4は決定的だが3pt。** 安全ルート。Sを狙うなら選ばない。
- **C6は弱い。** 30代MVPは遠藤・俊輔・憲剛の3人。単独では使えない。物語用。
- **C5はA群の高い代替。** J1優勝2回以上は遠藤・憲剛。C1/C2より高いが、ファンにはわかりやすい。
- **C1＋C5のような同じ群の組み合わせは無効。** 2人残る。ここで「手がかりの意味」を学ぶ。

### 8.5 難易度の確認

- 無料の手がかりで5人。多すぎず、少なすぎず。
- 1ptの手がかりで2人まで絞れる。2枚で1人。Sルートが明確。
- 3ptの決定的な手がかりで1人。ただし証拠20点でA止まり。
- 6pt全部使うと、証拠ペア次第でB/A。Sは難しい。
- 非ファンでも、容疑者カードの「海外」「通算得点」「最終季」「身長」を見れば解ける。
- ファンでも、憲剛と俊輔のどちらかで迷う。名前を知っているだけでは即答できない。
