# スタッツ探偵 — リニューアル設計パッケージ

> **状態: 垂直スライス実装済み。** チュートリアル、FILE 001、FILE 002、セーブ、PWA までアプリに反映済みです。  
> **前提:** Web PWA / スマホ優先 / 非ファンでも解ける / 有料級の品質 / 商用利用は一旦保留 / 写真は著作権クリアを条件に使用。

---

## 0. 結論

現在の「4つの独立したミニゲーム」を、**1つの推理事件**に置き換える。

- 名前を伏せた「謎の選手X」の事件カードを見る。
- 似た6人の容疑者カードを比較する。
- 6ポイントの捜査予算で「手がかり」を買い、容疑者を消していく。
- 最後に1人を告発し、**2枚の証拠**で推理を証明する。
- 正解後、名前・顔・キャリアの物語・数字の読み方を開示する。

この形にすると、**サッカーを知らなくても「容疑者カードの照合パズル」として解ける**。同時に、ファンには「名前を知っているから解ける」のではなく「知っていると物語が刺さる」という二層の楽しさになる。

## 1. この設計で変えること

| 現在 | リニューアル後 |
|---|---|
| 数字当て → ポジション当て → キャリア描画 → 4択、と4つの独立した課題 | 事件カード → 容疑者6人 → 手がかり購入 → 消去 → 告発、という1本の推理 |
| 有名選手が国籍・身長・時代で即バレする | 同世代・同国籍・同ポジションの「似た6人」から選ぶ |
| 4択。外れても無料でスキップできる | 2枚の証拠で証明する。手がかりにはコストがある |
| 23点の線を指で描く（作業量が多い） | キャリア曲線は「見くらべる」材料。描画は任意の上級モードへ |
| 採点が不透明 | 正解50 / 証拠30 / 効率20 / 減点-10。レシートで内訳を表示 |
| クレジット画面で全選手が先にバレる | 未解決の選手はシルエット。解決後にコレクションへ |
| 1事件3分、10事件で終わり | 1事件5〜8分、50事件＋日替わり＋コレクション |

**残すもの:** 紙とインクの質感、朱色のスタンプ、青鉛筆の推理、網点写真、キャリアグラフ、正体判明の物語、用語ノート、タイプライター／判子の効果音。  
**足すもの:** 推理ボード、手がかりデッキ、証拠の鎖、セーブ／再開、日替わり、コレクション、実績、BGM、アクセシビリティ、PWA。

## 3. まず作るべきもの

**50事件を一気に作らない。** 最初は次の3事件だけを作る。

1. **TUTORIAL「はじめての事件」** — 4人・4手がかり・誘導つき。3分。
2. **FILE 001「途切れない線」** — 6人・8手がかり・通常難易度。6分。本資料のサンプル。
3. **FILE 002「左足の魔法」** — 6人・8手がかり・やや難。7分。サンプルとは逆に「海外3か国」と「MVP2回」で絞る事件。左足はタイトルとリビールの物語。

この3件で、**「非ファンがチュートリアルだけで解けるか」「6人の比較がスマホで読みやすいか」「2枚の証拠で気持ちよく決まるか」**を検証する。ここが通れば、10事件 → 50事件へ横展開する。

## 4. 未決事項（実装前に決める）

1. **最終的な写真アセット:** サンプルの6人のうち、小野・稲本・憲剛の3人は写真の用意が必要。サンプルJSONでは `photoStatus: "pending"` としている。
2. **商用化の判断:** 今回は保留。設計ではクレジット・出典・差し替え可能性を保持する。商用化時には肖像／パブリシティを再確認する。
3. **日替わり事件の配信方法:** 最初は端末内の固定スケジュール（90日分）でよい。オンラインランキングはVol.1後。
4. **描画モードの扱い:** 現在の「キャリア・ドロー」は上級者向けの任意モードに残すか、完全に削除するか。推奨は「残すが、事件の必須ステップにはしない」。
5. **価格とボリューム:** 50事件フルパッケージで¥1,000〜1,500を本命にする。10事件のVol.1単体は約1.5〜2時間なので、¥1,000では内容量が不足しやすい。Vol.1は¥500〜700の「第1巻」、Vol.1〜3（30事件）で¥1,000〜1,200、またはVol.1を20事件に増やす案を比較する。詳細は [`01-product-brief.md`](./01-product-brief.md) と [`07-roadmap.md`](./07-roadmap.md)。

## 5. この設計の合格条件

- 非ファンのプレイテストで、**チュートリアル後のFILE 001を、サッカー知識なしで5人中4人が解ける**。
- 1事件の中央値が**5〜8分**。3分未満だと「軽すぎ」、10分超だと「重すぎ」。
- 正解者の**70%以上が「証拠2枚で決まった」と理解できる**。
- 同じ事件を2回目に遊んだとき、**「もっと安い手がかりでSを狙う」**動機が生まれる。
- 画面を見た瞬間に「紙の事件ファイル」とわかり、現在の世界観より**一段階密度が高い**と感じる。
- 50事件ぶんのデータを、**JSONの検証スクリプトで破綻なくチェックできる**。
